# Driven by Data: India's Pre-Owned Car Market

### A Data Analytics Project | Excel • Python • SQL • Power BI

## 1. Project Overview

This project explores India's pre-owned car market using data analytics techniques. The objective is to analyse used-car listings, identify pricing patterns, understand the factors associated with car prices, and generate meaningful business insights.

The project follows an end-to-end data analytics workflow using Excel, Python, SQL, and Power BI.

## 2. Project Objectives

- Analyse used-car listing prices across different brands and cities.
- Understand the relationship between vehicle age and listed price.
- Examine the impact of kilometres driven on car prices.
- Compare prices across fuel types and transmission types.
- Study the relationship between ownership, accident history, and service history with listed prices.
- Identify unusually high-priced listings.
- Build an interactive Power BI dashboard.

## 3. Dataset Overview

- Dataset: India's Pre-Owned Car Market
- Total records: 15,000 listings
- Data type: Structured tabular data
- Key attributes: Brand, model, city, fuel type, transmission, vehicle age, kilometres driven, ownership, vehicle history, and listed price.

## 5. Project Workflow

### Phase 1: Excel
- Inspected the dataset and column structure.
- Identified missing values and duplicate records.
- Standardised text formatting.
- Performed initial data cleaning.

### Phase 2: Python
- Used Pandas for data inspection and cleaning.
- Analysed missing values and data types.
- Validated records and checked data consistency.
- Exported the cleaned dataset.

### Phase 3: SQL
- Imported the cleaned dataset into MySQL.
- Developed SQL queries to answer 10 business questions.
- Used aggregate functions, filtering, grouping, and statistical analysis.
- Identified high-price outliers using the IQR method.

### Phase 4: Power BI
- Created an interactive dashboard.
- Designed KPI cards and analytical charts.
- Added slicers for Brand, City, Fuel Type, and Transmission.
- Presented key findings through visualisations.

## 6. SQL Business Questions

1. What is the average listed price of used cars?
2. Which car brands have the highest average listed prices?
3. How do used-car prices vary across cities?
4. How does fuel type affect listed prices?
5. How does vehicle age relate to listed price?
6. How does kilometres driven relate to listed price?
7. Which transmission type has a higher average listed price?
8. Are accident history and service history associated with listed prices?
9. How does previous owner count relate to listed price?
10. Which listings have unusually high or low prices?

## 7. Key Findings

- Average listed price: ₹4,75,983.44.
- Maximum listed price: ₹80,59,000.
- BMW recorded the highest average listed price among the analysed brands.
- Hyderabad recorded the highest average listed price among the analysed cities.
- Hybrid vehicles recorded the highest average listed price among fuel types.
- Newer vehicles generally had higher average listed prices.
- Vehicles with lower kilometres driven generally had higher average listed prices.
- Automatic vehicles had a higher average listed price than manual vehicles.
- First-owner vehicles had higher average listed prices than vehicles with multiple previous owners.
- The IQR method identified 801 potential high-price outliers above ₹11,54,500.

*Note: These are observed associations in the dataset and do not establish causation.*
